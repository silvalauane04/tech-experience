PROJETO TECH EXPERIENCE 2026

1. Coloque os quatro arquivos na pasta tech-experience.
2. Abra o terminal dentro dessa pasta.
3. Execute: php -S localhost:8000
4. No navegador, acesse: http://localhost:8000/index.html

O formulário envia os dados por POST para processar.php.
É necessário ter PHP 8+ instalado. A função mb_strlen requer a extensão mbstring habilitada.
